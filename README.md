# ECE PCB Design Projects

## Overview

Welcome to my PCB Design Projects repository.

This repository contains a collection of electronic circuit and PCB designs created using **KiCad** as part of my learning journey in **Electronics and Communication Engineering (ECE)**.

The goal of these projects is to strengthen my understanding of:

* Schematic design
* PCB layout
* Component selection
* Circuit simulation
* PCB routing
* Power electronics
* Embedded systems
* Hardware design

Most of the projects currently focus on **PCB design and 3D visualization**. Future updates will include PCB fabrication, hardware testing, performance analysis, and design optimization.
