# LM2596 Adjustable Buck Converter

## Overview

This project presents the PCB design of an **LM2596-based adjustable buck converter** developed using **KiCad**.

A buck converter is a DC-to-DC power converter that efficiently reduces a higher input voltage to a lower output voltage while minimizing power loss. This design focuses on creating a compact, adjustable, and efficient power supply suitable for electronics prototyping and embedded system applications.
